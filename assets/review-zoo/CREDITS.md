Tiny Creatures 1.0 by **Clint Bellanger**, an expansion in Kenney's Tiny style.

`sprites.json` losslessly represents the nontransparent pixels of slime tiles 0081–0089 and scenery tiles 0095, 0141, 0148, 0150, 0178 from `Tilemap/tilemap_packed.png`
(with the original transparency) as colored SVG rectangles. No third-party runtime or external image
requests are needed when GitHub renders the generated SVG. Slime families each
use three original sizes/forms for LV1 → LV2 → LV3. HUD/layout is custom.

Arcade lettering, clouds, flowers, coins, hearts, cabinet, and stage UI are
code-native SVG art in `scripts/review-zoo/pixel-art.mjs`. Creature outlines
and colors remain those of the original CC0 atlas.
